# 💳 Bank Transaction Analysis

A data visualization project using **Power BI**, with backend data preparation and integration done using **Python**, **SQL** and **Excel**. This dashboard provides insights into transaction statuses, fraud detection, and regional transaction patterns.

---

## 📊 Project Overview

This dashboard helps analyze and interpret banking transaction data across various dimensions:
- Transaction status: Success vs. Failed
- Fraud detection: Flagged vs. Legitimate
- Transaction types: Deposit, Withdrawal, Transfer
- Regional distribution of transactions
- Trends over time

---

## 🛠️ Tools & Technologies Used

- **Power BI**: Dashboard creation and data visualization  
- **Python (Pandas)**: Data cleaning and preprocessing  
- **SQL**: Data extraction and transformation

## 🔍 Insights Gained

- **51.9%** of transactions were **fraudulent**, requiring further review  
- Slightly more **failed transactions** (513) compared to **successful ones** (487)  
- Most common transaction type: **Deposit**
